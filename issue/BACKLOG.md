# Backlog Ide & Fitur Masa Depan

Daftar fitur, ide, atau perbaikan di luar cakupan tahap aktif yang dapat dikerjakan di kemudian hari.

- [ ] Registrasi mandiri pengguna (self-registration)
- [ ] Fitur lupa password & reset password via token email
- [ ] Fitur ubah password di profil pengguna
- [ ] Proteksi CSRF token untuk semua form transaksi
- [ ] Rate limiting pada endpoint login (mencegah brute-force)
- [ ] Penyimpanan session di database SQLite (misal connect-sqlite3)
- [ ] Export laporan tiket ke PDF / Excel
- [ ] Notifikasi email menggunakan Nodemailer
- [ ] Upload lampiran file/gambar pada tiket
- [ ] Fitur SLA (Service Level Agreement) peringatan jatuh tempo tiket
- [ ] Filter & pencarian lanjutan pada daftar tiket
- [ ] Dark mode toggle
